# Training and testing dataset

The included cryptographic inference dataset comes from controlled synthetic IPsec captures generated by [`pcap_factory/factory.py`](pcap_factory/factory.py). Labels come from the known test configuration encoded in each capture filename; they are not predictions or manually assigned labels from real production traffic.

| Artifact | Purpose | Size |
| --- | --- | ---: |
| [`pcap_factory/captures/`](pcap_factory/captures/) | Successful source PCAPs used to extract features | 157 captures |
| [`feature_extractor/dataset.csv`](feature_extractor/dataset.csv) | Extracted capture features with source filename and labels | 157 rows |
| [`feature_extractor/ml_dataset.csv`](feature_extractor/ml_dataset.csv) | ML table with source filename removed | 157 rows |
| [`feature_extractor/ml/train.csv`](feature_extractor/ml/train.csv) | Training split, repetitions 1–4 | 126 rows |
| [`feature_extractor/ml/test.csv`](feature_extractor/ml/test.csv) | Held-out split, repetition 5 | 31 rows |

The successful captures contain 113 ICMP and 44 TCP scenarios. They cover the synthetic cipher, hash, DH, and PFS combinations named in their filenames. The repository does not contain labeled VoIP, video, web-browsing, or bulk-transfer workload captures. The dashboard's workload categories are therefore a rule-based metadata baseline, not a validated supervised workload model.

The four bundled Random Forest models in [`feature_extractor/ml/models/`](feature_extractor/ml/models/) predict encryption, hash, DH group, and PFS class from 18 numeric capture features. `repetition`, `traffic`, the filename, addresses, and SPIs are excluded from model inputs. [`feature_extractor/make_split.py`](feature_extractor/make_split.py) separates repetitions before training; [`feature_extractor/ml/train_final_models.py`](feature_extractor/ml/train_final_models.py) trains the bundled model format. See [`ML_MODEL.md`](ML_MODEL.md) for the feature list and inference contract.

This is a small controlled dataset. Repeated captures can share nearly identical configurations and packet shapes across the train/test split, so held-out repetition results must not be interpreted as generalization to unseen organizations, devices, or applications. The displayed AI confidence is the mean predicted-class probability of available cryptographic models; it is not measured model accuracy. Exact negotiated settings should be confirmed from packet-visible transforms or authorized gateway telemetry.
